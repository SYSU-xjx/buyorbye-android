## Corrections made during verification

- Guard group creation/join and channel-save callbacks after the view or dialog closes.
- Block concurrent vote submissions and reuse the request UUID when retrying identical content.
- Apply local muted words and blocked display names to the live Plaza feed.
- Initialize screen content once after the view is ready, then reset state on view destruction.
  This also removes the pathological recursive lint scan from onCreateView without disabling lint.
- Cancel Home polling and dismiss dialogs when their view is destroyed.

## Coverage limits and release notes

- The successful image-upload, deletion and four-image limit checks exercised HTTP APIs.
  Selecting/uploading images through every device's gallery app was not fully exercised.
- Currency totals are per-currency. The savings leaderboard is CNY only.
  The spender leaderboard measures approved amounts converted to HKD.
- Muted words and blocking are device-local. Blocking currently matches display names,
  because the feed does not expose a stable author ID for an account-level blacklist.
- Group icons are supported in Preview; the live group API stores names without icons.
- Live screens and Preview are separate modes. Preview records and random browsing do not
  count as verification of the corresponding server features.
- Current automated UI coverage uses one API 34 emulator. Other Android versions,
  real-device galleries, process death during an upload, and prolonged network interruptions
  remain outside this run.
- The emulator retained the app session after a normal app restart. Expired-token behavior
  still follows the existing redirect-to-login policy.
